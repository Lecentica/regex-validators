# Regex Input Validators & Text Parser

Java program demonstrating regex-based input validation and text processing:
email validation, password complexity checking, phone number parsing with 
international format support, hashtag extraction, and file-based word 
filtering.

## Key Concepts
- Regular expressions for input validation and pattern matching
- Password complexity rules (length, uppercase, digit, special character)
- File I/O with Scanner
- Pattern and Matcher classes for extraction

## How to Run
javac *.java

java Main

(requires TheRaven.dat in working directory for one feature)
